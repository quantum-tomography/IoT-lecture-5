Mozi: The Botnet That Took Over IoT Traffic

A case study based on IBM X-Force research (historical observations from 2019–2020)

In plain words

Mozi is malware that takes over internet-connected devices and links them into a botnet: a group of machines attackers can remotely control.

2. Why Mozi mattered

~90%

of IBM-observed IoT botnet traffic during October 2019–June 2020 was attributed to Mozi.

+400%

combined observed IoT attack instances in that period versus the preceding two years, according to IBM.

Mozi did not simply replace other threats; it appeared amid a dramatic expansion in observed malicious activity.

These are IBM's historical observations, not today's global infection rates.

3. Which devices were exposed?

At home

📷 IP cameras, 📡 routers, 📺 DVRs, smart appliances.

At work

Network equipment, industrial controls and other IoT devices.

Many devices run firmware with built-in web management pages. Poor security settings or outdated software can expose them.

Think: How many internet-connected devices are in an ordinary household? Which ones receive updates?

4. How infection starts

⬇️ Malicious file
→
🕸️ Infected bot

IBM found that nearly all observed initial IoT targeting attempts used CMDi — tricking an insecure device into running unintended system commands.

Mozi could also try weak Telnet passwords. The attacker exploited a weakness; the owner did not knowingly install Mozi.

Analogy: A visitor types instructions into a form meant only to accept a name, and the machine mistakenly obeys the instructions.

4. Carries out tasks
  • Mozi can disguise its process name as a legitimate-looking service.
  • It can change firewall rules to block certain remote-access connections.
  • It can download and run additional malicious software.

These behaviors were documented in the IBM-analyzed samples; not every infected device behaves identically.

6. Mozi's unusual network: peer-to-peer

Centralized control

🎛️ Central server
↓
Bots

Many bots rely on one central C2 service.

Mozi's P2P design

Bot A ↔ Bot B
↕ Bot C ↔ Bot D

P2P bots discover and communicate with other bots, using a customized DHT.

There is no need for every bot to contact one central server. This can make disruption more difficult, although it does not make the botnet unstoppable.

7. What could Mozi do?

🌊 DDoS

Flood an online service with traffic so ordinary users struggle to reach it.

💻 Remote commands

Run instructions on compromised devices without the owner's permission.

⬇️ Download malware

Fetch and execute additional malicious files.

📋 Collect bot information

Report information about infected devices.

8. Why weak passwords are dangerous

Mozi also attempted brute-force logins using a built-in list of common or default credentials.

Interactive thought experiment

A camera has a default admin password. What is the safest action?

A password change helps against guessing, but does not fix a software vulnerability such as command injection.

9. How to defend against Mozi-like threats

For households

  • Change default passwords.
  • Install vendor patches and firmware updates.
  • Disable unused remote access, especially Telnet.
  • Keep unneeded management pages off the public internet.

For organizations

  • Keep an asset inventory.
  • Separate IoT devices using network segmentation.
  • Review logs and suspicious network traffic.
  • Test for command injection and other weaknesses.

Defenses combine good configuration, updates, reduced exposure and monitoring.
